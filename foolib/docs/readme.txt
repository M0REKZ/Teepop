3. Unix/Linux

3.1 Requirements For Compiling In Unix/Linux:
python
g++
xlib
opengl

3.2 Unix/Linux Quick Compile How To (for test ginger):
Go to base directory foolib/
Issue commands:
# mkdir workspace
# cd workspace
# mkdir ginger
# cd ginger
# python ../../scripts/build.py ../../tests/ginger/ginger.xml
And then you'll find the binary in output/

The same goes for the other tests in foolib/tests/ directory.
